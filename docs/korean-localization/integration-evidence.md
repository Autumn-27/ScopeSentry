인증 화면이 정상 로드됐지만 실제 로그인 HTTP 상태 코드는 확인하지 않았음.

## 발견한 제한사항

- 빈 테이블의 No Data가 영어로 표시됨.
- 프로젝트 탭의 All (0)과 검색:: 표시 확인. 번역·구두점 개선 검토 필요.
- api.success, api.system.version.success가 토스트로 표시됨. 백엔드 메시지 매핑은 별도 검토 필요.
- 플러그인 소개는 중국어 원문, 모듈·실행 매개변수는 원형 유지됨. UI 키와 서버 콘텐츠를 구분해야 함.
- 1280×720에서 스캔 작업의 ‘작업 이름’, 플러그인의 ‘플러그인 키’가 줄바꿈됨. 자산 헤더는 가로 스크롤이 필요하며 긴 탭은 잘려 탐색됨.
- 좁은 뷰포트에서 대시보드 집계 카드 내용이 잘림. 1280×720에서는 집계 카드 텍스트 확인함.
- 작업 추가 폼은 세로 스크롤이 필요하고 노드 선택 안내가 축약됨. 아래쪽 항목의 시각 검사는 제한적임.
- API·DB·Go·스캔 로직은 수정하지 않음. 운영 데이터 변경 작업 수행하지 않음.

## 공개 스크린샷

브라우저 뷰포트 1280×720에서 필요한 영역만 직접 캡처함. 실제 인증 화면이며 합성 데이터·이미지 덧칠 없음.
전체 화면 원본은 저장하지 않음. 계정명, 노드 식별자, 내부 IP, 실제 자산·API Key·토큰을 제외하도록 브라우저 캡처 영역을 제한함.
JPEG 캡처를 PNG로 형식 변환했으며 픽셀 내용은 추가 편집하지 않음.

## 코드·Git 및 후속 검토

로그인 토큰 콘솔 출력은 테스트 중 임시로 억제했으며 종료 후 원본 바이트로 복원함.
‘로그인 정보 기억’ 해제 상태를 사용자 인증 전 확인함. 인증 이후 브라우저 저장소는 읽거나 내보내지 않음.
실행 중 Vite 서버를 재사용했으며 중복 실행하지 않음. 기존 Commit은 변경하지 않음.
이번 문서 Commit에는 README 2개, 이 검증 문서와 PNG 5개만 포함 예정.
프록시 설정, 개인 작업 로그, 출력 디렉터리, 로그인 소스 변경은 포함하지 않음.
이번 회차에서는 소스 빌드·TypeScript·번역 키 검사를 재실행하지 않음. 과거 검사 결과를 이번 회차 통과로 간주하지 않음.

PR은 위 제한사항을 명시한 문서·조회 증적 제출 범위로 준비 가능. 전체 회귀 통과 또는 완전한 한국어화로 설명하면 안 됨.
Push·PR 생성 및 Kali 배포는 수행하지 않음.
