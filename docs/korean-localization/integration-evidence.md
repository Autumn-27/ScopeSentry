# 한국어 UI 3차 품질 개선 및 연동 검증

검증일: 2026-11-12. 비교 기준: 25f63fd68478205a31ea6878d09f522f42bfa998.
Windows에서 실행 중인 Vite 서버와 사용자가 로그인한 세션을 재사용함. Kali 서버·Docker·DB·스캔 설정은 변경하지 않음.
이 문서는 앞선 인증 후 조회 기록을 갱신함. 이전 캡처와 문서는 기준 Commit 이력에서 확인 가능.

프로젝트 다중 선택의 Yes/No도 기존 common.on/off 키로 표시함.
번역 키는 857개에서 API 메시지 2개가 추가되어 각 언어 859개임.

## API 메시지 처리 범위

Go 소스에서 응답 헬퍼는 i18n.Translate 결과를 message에 넣고, 번역 실패 시 원래 키를 반환함.
로컬 소스 분석과 실행 화면 관찰을 종합하면 이 원래 키가 Axios를 거쳐 노출되는 경로를 확인할 수 있음.
배포된 Kali 서버의 파일·번역 카탈로그 자체는 검사하지 않았으므로 서버의 번역 실패 원인까지 확정하지 않음.

- api.success와 api.system.version.success를 영어·중국어·한국어 카탈로그에 등록함.
- 현재 언어 또는 영어에 실제 등록된 키만 번역함. 일반 문장·알 수 없는 키는 원문 유지.
- 키 접두사나 success 단어만으로 성공을 추정하지 않음. 성공/오류 토스트 채널은 기존 code 판단 유지.
- HTTP 오류 경로도 message 부분만 번역하고 기존 추가 오류 데이터와 401 처리 유지.
- response 객체·message 필드·상태 코드·인증·API·비즈니스 로직은 변경하지 않음.
- HTML 렌더링 옵션·문자열 실행은 추가하지 않음. 메시지는 Element Plus의 기본 텍스트 경로 사용.
- 서버가 이미 번역한 일반 문장, 미등록 키, 플러그인 소개·로그·실행 매개변수는 이번 변경으로 번역하지 않음.

## 공개 증적

README에는 대표 이미지 5개만 표시함: 대시보드·자산·작업·플러그인·프로젝트.
수정된 자산·작업·플러그인 이미지는 재촬영했고 프로젝트 이미지를 추가함.
이전 이미지와 해시·시각 비교 후 같은 파일을 갱신하여 중복 이미지는 추가하지 않음.
화면이 동일한 데스크톱 대시보드·시스템 제목 이미지는 기존 파일 유지.

모든 공개 이미지는 실제 브라우저 부분 캡처임. 합성 데이터·덧칠 편집 없음.
계정 표시 영역·노드 식별자·운영 자산 행·설정값을 캡처 범위에서 제외함.
JPEG 브라우저 캡처를 PNG로 형식 변환했으며 픽셀을 추가 편집하지 않음. 전체 화면 원본은 저장하지 않음.
자산·작업·프로젝트 1280×670, 플러그인 1280×277, 기존 대시보드 1216×180.
기존 시스템 설정 제목 이미지는 1280×130이며 README에서 별도 링크로 유지함.

## 잔여 위험·PR 범위

- 플러그인 소개의 중국어, 모듈명·명령어·원본 데이터·서버 문장은 원형 유지.
- 미등록 API 메시지 키는 원문으로 보일 수 있음. 모든 서버 메시지를 포괄한다고 주장하지 않음.
- 일부 긴 탭은 기존 가로 스크롤·축약 동작 유지. 전체 탭 구조 변경은 별도 과제.
- 작업 추가 폼의 세로 스크롤과 긴 선택 안내 축약은 유지됨.
- 언어 전환 승인 시 콘텐츠 하위 트리를 재생성하므로 미저장 입력이 초기화될 수 있음. 기존 확인창 유지.
- 요청된 Draft PR은 위 제한과 기존 TypeScript 실패를 명시하는 조건으로 제출 준비 가능.
- Go·DB·운영 설정·라이선스 고지·기존 Git 이력은 변경하지 않음. Push·PR 생성 수행하지 않음.
